# FSD Team Collaboration Project

## Project Description

This project demonstrates collaborative software development using GitHub.

## Features

* Login Page
* Git Branching
* GitHub Issues
* Pull Requests
* Code Reviews
* Project Documentation

## Technologies Used

* HTML
* Git
* GitHub

## GitHub Collaboration Workflow

1. Create a GitHub repository
2. Create an Issue for a task
3. Create a separate branch
4. Develop the feature
5. Commit the changes
6. Push the branch to GitHub
7. Create a Pull Request
8. Perform code review
9. Merge the Pull Request into the main branch
10. Update project documentation

## Project Files

* `README.md` - Project documentation
* `login.html` - Simple login page

## Conclusion

The project demonstrates how GitHub can be used for team collaboration through repositories, branches, Issues, Pull Requests, code reviews, and documentation.
